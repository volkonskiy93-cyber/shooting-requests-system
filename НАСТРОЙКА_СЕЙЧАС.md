### ШАГ 1: Подготовка Gmail/Yandex SMTP (5 минут)

#### Вариант A: Gmail (РЕКОМЕНДУЕТСЯ)

1. **Включите двухфакторную аутентификацию:**
   - Откройте: https://myaccount.google.com/security
   - Включите "2-Step Verification"

2. **Создайте пароль приложения:**
   - Откройте: https://myaccount.google.com/apppasswords
   - Выберите "Mail" → "Other (Custom name)"
   - Введите: "Serverless Function"
   - Нажмите "Generate"
   - **✅ СКОПИРУЙТЕ пароль** (16 символов, например: `abcd efgh ijkl mnop`)

#### Вариант B: Yandex

1. **Создайте пароль приложения:**
   - Откройте: https://passport.yandex.ru/profile
   - Перейдите в "Безопасность"
   - Создайте пароль приложения для почты
   - **✅ СКОПИРУЙТЕ пароль**

### ШАГ 4: Настройка переменных окружения в Vercel (3 минуты)

1. **В панели Vercel:**
   - Откройте ваш проект
   - Перейдите: **Settings** → **Environment Variables**

2. **Добавьте переменные:**

   **Для Gmail:**
   ```
   Имя: SMTP_HOST
   Значение: smtp.gmail.com
   Окружение: Production, Preview, Development (выберите все)
   
   Имя: SMTP_PORT
   Значение: 587
   Окружение: Production, Preview, Development
   
   Имя: SMTP_SECURE
   Значение: false
   Окружение: Production, Preview, Development
   
   Имя: SMTP_USER
   Значение: ваш_email@gmail.com  (ваш Gmail адрес)
   Окружение: Production, Preview, Development
   
   Имя: SMTP_PASSWORD
   Значение: ваш_пароль_приложения  (16 символов из шага 1)
   Окружение: Production, Preview, Development
   ```

   **Для Yandex:**
   ```
   Имя: SMTP_HOST
   Значение: smtp.yandex.ru
   
   Имя: SMTP_PORT
   Значение: 465
   
   Имя: SMTP_SECURE
   Значение: true
   
   Имя: SMTP_USER
   Значение: ваш_логин@yandex.ru
   
   Имя: SMTP_PASSWORD
   Значение: ваш_пароль_приложения
   ```

3. **Нажмите "Save"** для каждой переменной

4. **Важно:** После добавления переменных нужно **передеплоить проект**:
   - Перейдите: **Deployments**
   - Найдите последний деплой
   - Нажмите **"..." → "Redeploy"**

## 🆘 Если что-то не работает:

### Проблема: "SMTP credentials not configured"
**Решение:** Проверьте, что все переменные окружения добавлены в Vercel и применены ко всем окружениям (Production, Preview, Development)

### Проблема: "Authentication failed"
**Решение:** 
- Для Gmail: используйте пароль приложения, а не основной пароль
- Убедитесь, что двухфакторная аутентификация включена
- Проверьте, что SMTP_USER - это полный email адрес

### Проблема: Письма не приходят
**Решение:**
- Проверьте папку "Спам"
- Проверьте логи в Vercel → Deployments → последний деплой → Functions → View Function Logs
- Убедитесь, что переменные окружения применены (передеплойте проект после добавления переменных)

### Проблема: Serverless функция не вызывается
**Решение:**
- Убедитесь, что проект задеплоен на Vercel
- Проверьте URL: должен быть доступен `/api/send-email`
- Откройте консоль браузера (F12) и проверьте ошибки
