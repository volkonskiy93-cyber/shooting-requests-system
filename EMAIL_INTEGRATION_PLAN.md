# План интеграции отправки Email с Word файлами

## Проблема
Браузеры не могут напрямую отправлять email с вложениями. Нужен серверный компонент или API сервис.

## Варианты решения:

### ✅ Вариант 1: EmailJS (РЕКОМЕНДУЕТСЯ для начала)
**Преимущества:**
- Работает прямо из браузера (без backend)
- Бесплатный план: 200 писем/месяц
- Простая интеграция
- Поддерживает вложения

**Как работает:**
1. Регистрация на emailjs.com (бесплатно)
2. Настройка email сервиса (Gmail, Outlook, etc.)
3. Интеграция в код (1-2 строки JavaScript)
4. Автоматическая отправка Word файла при создании заявки

**Ограничения:**
- Бесплатно до 200 писем/месяц
- Нужна настройка email сервиса один раз
- Адрес получателя настраивается в EmailJS или передается в коде

---

### Вариант 2: Backend на Node.js (Firebase/Vercel)
**Преимущества:**
- Полный контроль
- Авторизация пользователей
- Без ограничений на количество писем
- Хранение истории отправки

**Как работает:**
1. Backend функция (Node.js/Python)
2. Использование библиотек: Nodemailer (Node.js) или smtplib (Python)
3. Авторизация через Firebase Auth или собственный сервис
4. Отправка через SMTP сервер

**Требования:**
- Настройка backend сервера
- SMTP доступ (Gmail, Outlook, или свой сервер)

---

### Вариант 3: Formspree / SendGrid API
**Преимущества:**
- Готовые API сервисы
- Надежность
- Аналитика

**Ограничения:**
- Платные планы для больших объемов
- Требует настройки API ключей

---

## Рекомендация: EmailJS

**Почему EmailJS:**
- ✅ Самый простой для реализации
- ✅ Не требует backend сервера
- ✅ Работает сразу после настройки
- ✅ Достаточно для внутреннего использования
- ✅ Бесплатный план покрывает большинство случаев

**С авторизацией по email:**
- Можно хранить email адрес в localStorage после "логина"
- Или делать простую форму входа (без пароля, только email)
- Email будет браться из профиля авторизованного пользователя
