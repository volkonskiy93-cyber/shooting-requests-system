🎯 СПОСОБ 1: ЧЕРЕЗ BAT-ФАЙЛ (САМЫЙ ПРОСТОЙ)
─────────────────────────────────────────────────────────────
Просто дважды кликните на файл:
    📄 ЗАПУСТИТЬ_БОТА.bat
    
Он автоматически:
    ✅ Установит зависимости
    ✅ Запустит бота

─────────────────────────────────────────────────────────────

🎯 СПОСОБ 2: ЧЕРЕЗ ПРОВОДНИК WINDOWS
─────────────────────────────────────────────────────────────
1. Откройте папку проекта в проводнике
2. Кликните ПРАВОЙ кнопкой мыши в пустом месте папки
3. Выберите "Открыть в терминале" или "Open in Terminal"
   (Если такой опции нет, см. способ 3)

─────────────────────────────────────────────────────────────

🎯 СПОСОБ 3: ЧЕРЕЗ МЕНЮ ПУСК
─────────────────────────────────────────────────────────────
1. Нажмите клавишу Windows
2. Введите "PowerShell" или "cmd"
3. Нажмите Enter
4. В открывшемся окне введите:
   cd "c:\Исходники DaVinci\дут"
5. Нажмите Enter

─────────────────────────────────────────────────────────────

🎯 СПОСОБ 4: ЧЕРЕЗ CURSOR (РЕДАКТОР КОДА)
─────────────────────────────────────────────────────────────
1. В Cursor нажмите: Ctrl + ` (обратная кавычка)
   ИЛИ
2. Меню: Terminal → New Terminal
   ИЛИ
3. Меню: View → Terminal

Терминал откроется в папке проекта автоматически!

─────────────────────────────────────────────────────────────

🎯 СПОСОБ 5: ЧЕРЕЗ АДРЕСНУЮ СТРОКУ ПРОВОДНИКА
─────────────────────────────────────────────────────────────
1. Откройте папку проекта в проводнике
2. Кликните в адресной строке (где путь к папке)
3. Введите: cmd
4. Нажмите Enter

─────────────────────────────────────────────────────────────

💡 РЕКОМЕНДУЕМЫЙ СПОСОБ
─────────────────────────────────────────────────────────────
Используйте файл ЗАПУСТИТЬ_БОТА.bat - это самый простой способ!
