ВАРИАНТ A: Через GitHub (РЕКОМЕНДУЕТСЯ)

1. Если проект уже в GitHub:
   → В Vercel нажмите "Add New Project"
   → Выберите репозиторий
   → Нажмите "Import"

   → Нажмите "Deploy"

2. Если проект НЕ в GitHub:
   → Сначала загрузите проект в GitHub
   → Затем выполните пункт 1 выше

   cd "c:\Исходники DaVinci\дут"

2. Введите команды:

3. Следуйте инструкциям на экране
