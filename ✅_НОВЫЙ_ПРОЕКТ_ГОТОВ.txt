БЫСТРЫЙ СПОСОБ СОЗДАНИЯ
═══════════════════════════════════════════════════════════════

1. Откройте: https://github.com/new

2. Заполните форму:
   Repository name: shooting-requests-system
   Description: Система заявок на видеосъемку - программа Доброе утро
   Public
   НЕ ставьте галочки (README, .gitignore, license)

3. Нажмите "Create repository"

4. После создания репозитория загрузите файлы:
   - Нажмите "Add file" → "Upload files"
   - Перетащите файлы или выберите их
   - Commit changes

НАСТРОЙКА VERCEL
═══════════════════════════════════════════════════════════════

После загрузки файлов на GitHub:

1. Откройте: https://vercel.com/dashboard
2. Нажмите "Add New Project"
3. Выберите репозиторий: shooting-requests-system
4. Framework Preset: Other
5. Root Directory: ./
6. Build Command: (оставьте пустым)
7. Output Directory: ./
8. Нажмите "Deploy"

Vercel автоматически задеплоит проект и даст вам ссылку.
