## 🤖 Создание бота

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "Мой бот рассылки")
   - Введите username бота (должен заканчиваться на `bot`, например: `my_broadcast_bot`)
4. **Сохраните токен**, который выдаст BotFather (выглядит как: `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

## 📦 Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

Это установит необходимые пакеты:
- `node-telegram-bot-api` - для работы с Telegram Bot API
- `dotenv` - для работы с переменными окружения

## 🔑 Настройка токена

### Вариант 1: Через файл .env (рекомендуется)

1. Создайте файл `.env` в корне проекта
2. Добавьте в него:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_здесь
   ```
3. Замените `ваш_токен_здесь` на токен, полученный от BotFather

### Вариант 2: Через bot_config.json

1. Откройте файл `bot_config.json`
2. Добавьте токен в поле `token`:
   ```json
   {
     "token": "ваш_токен_здесь",
     "recipients": []
   }
   ```


Для работы на Vercel нужно создать serverless функцию. Создайте файл `api/bot.js`:


## 💬 Использование команд

### Основные команды:

- `/start` - Начать работу с ботом, показать приветствие
- `/help` - Показать справку по всем командам
- `/add` - Добавить текущий чат в список получателей рассылки
- `/remove` - Удалить текущий чат из списка получателей
- `/list` - Показать список всех получателей (их ID)
- `/test` - Отправить тестовое сообщение себе
- `/broadcast <сообщение>` - Отправить сообщение всем получателям

### Пример использования:

1. **Добавление получателей:**
   ```
   /add
   ```
   Бот добавит ваш чат в список получателей.

2. **Проверка списка:**
   ```
   /list
   ```
   Бот покажет количество и ID всех получателей.

3. **Отправка рассылки:**
   ```
   /broadcast Привет! Это тестовая рассылка.
   ```
   Бот отправит сообщение всем получателям.

## 🌐 API для рассылки

Вы можете отправлять рассылки через HTTP запросы к API endpoint.

### Endpoint: `/api/broadcast`

**Метод:** POST

**Тело запроса (JSON):**
```json
{
  "message": "Текст сообщения для рассылки",
  "secret": "секретный_ключ" // опционально
}
```

**Пример запроса (curl):**
```bash
curl -X POST https://ваш-домен.vercel.app/api/broadcast \
  -H "Content-Type: application/json" \
  -d '{"message": "Привет из API!"}'
```

**Пример запроса (JavaScript):**
```javascript
fetch('https://ваш-домен.vercel.app/api/broadcast', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    message: 'Привет из API!'
  })
})
.then(res => res.json())
.then(data => console.log(data));
```

**Ответ (успех):**
```json
{
  "success": true,
  "message": "Рассылка выполнена",
  "stats": {
    "total": 5,
    "success": 5,
    "failed": 0
  }
}
```

**Ответ (ошибка):**
```json
{
  "error": "Сообщение не указано"
}
```

### Настройка секретного ключа (опционально)

Для защиты API можно установить переменную окружения:
```
BROADCAST_SECRET=ваш_секретный_ключ
```

Затем в запросе передавайте этот ключ:
```json
{
  "message": "Сообщение",
  "secret": "ваш_секретный_ключ"
}
```

## ⚠️ Важные замечания

1. **Токен бота** - это секретная информация, не публикуйте его в открытом доступе!
2. **Список получателей** хранится в `bot_config.json` - этот файл можно редактировать вручную
3. Если пользователь заблокировал бота, он автоматически удаляется из списка получателей
4. Для работы на Vercel может потребоваться настройка webhook вместо polling

## 🔧 Решение проблем

### Бот не отвечает
- Проверьте, что токен указан правильно
- Убедитесь, что бот запущен (`npm run bot`)
- Проверьте интернет-соединение

### Ошибка "Токен не найден"
- Создайте файл `.env` с токеном
- Или добавьте токен в `bot_config.json`

### Сообщения не доставляются
- Проверьте, что получатели добавили бота (`/add`)
- Убедитесь, что получатели не заблокировали бота
- Проверьте список получателей командой `/list`
