🚀 Автоматическое обновление файлов на GitHub

ШАГ 1: Создайте токен доступа GitHub

1. Откройте: https://github.com/settings/tokens

2. Нажмите "Generate new token" → "Generate new token (classic)"

3. Название: "Обновление проекта"

4. Срок: "90 days" или "No expiration"

5. Выберите права: ✅ repo (полный доступ к репозиториям)

6. Нажмите "Generate token"

7. ⚠️ Скопируйте токен (он показывается только один раз!)

ШАГ 2: Введите токен и обновите файлы

⚠️ Токен будет использован только для обновления файлов в этом браузере. Он не сохраняется и не передается никуда.
