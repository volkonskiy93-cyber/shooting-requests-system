  ЗАГРУЗКА НА GITHUB PAGES (2 МИНУТЫ)
═══════════════════════════════════════════════════════

ШАГ 1: СОЗДАНИЕ РЕПОЗИТОРИЯ
───────────────────────────────────────────────────────
1. Откроется страница создания репозитория на GitHub
2. Название: shooting-applications (или любое)
3. Выберите: Public (публичный)
4. НЕ ставьте галочки на README, .gitignore
5. Нажмите: "Create repository"

ШАГ 2: ЗАГРУЗКА ФАЙЛОВ
───────────────────────────────────────────────────────
1. Нажмите кнопку: "uploading an existing file"
2. Откройте папку: c:\Users\user\Desktop\дут
3. Перетащите ТОЛЬКО эти 5 файлов:
   
   ✓ index.html
   ✓ deepseek_htmlобщая.html
   ✓ admin.html
   ✓ admin.js
   ✓ data.js

4. Внизу напишите: Initial commit
5. Нажмите: "Commit changes"

ШАГ 3: ВКЛЮЧЕНИЕ GITHUB PAGES
───────────────────────────────────────────────────────
1. В репозитории нажмите: Settings (вверху)
2. В меню слева: Pages
3. Source: Branch → main, Folder → / (root)
4. Нажмите: Save

ШАГ 4: ПОЛУЧЕНИЕ ССЫЛКИ
───────────────────────────────────────────────────────
Через 1-2 минуты ссылка будет:
https://ваш-username.github.io/shooting-applications/
