У вас нет Python? Не проблема! Есть несколько способов:

═══════════════════════════════════════════════════════════════
СПОСОБ 1: ЧЕРЕЗ BAT-ФАЙЛ (САМЫЙ ПРОСТОЙ)
═══════════════════════════════════════════════════════════════

1. Дважды кликните на файл: update.bat
2. Дождитесь завершения обновления
3. Готово!

═══════════════════════════════════════════════════════════════
СПОСОБ 2: ЧЕРЕЗ HTML ФАЙЛ С NODE.JS
═══════════════════════════════════════════════════════════════

1. Установите Node.js: https://nodejs.org/
   (Бесплатно, быстро устанавливается)

2. Откройте командную строку в папке с файлами

3. Выполните команду:
   npx http-server -p 8000

4. Откройте в браузере:
   http://localhost:8000/UPDATE_GITHUB.html

5. Нажмите кнопку "Обновить файлы"

═══════════════════════════════════════════════════════════════
СПОСОБ 3: ЧЕРЕЗ POWERSHELL НАПРЯМУЮ
═══════════════════════════════════════════════════════════════

1. Откройте PowerShell в папке с файлами

2. Выполните команду:
   Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process

3. Выполните:
   .\update_github_simple.ps1

═══════════════════════════════════════════════════════════════
СПОСОБ 4: РУЧНОЕ ОБНОВЛЕНИЕ ЧЕРЕЗ GITHUB
═══════════════════════════════════════════════════════════════

1. Откройте: https://github.com/volkonskiy93-cyber/-2

2. Для каждого файла (index.html, deepseek_htmlобщая.html, admin.html):
   - Нажмите на файл
   - Нажмите кнопку "✏️ Edit" (карандаш)
   - Скопируйте содержимое локального файла
   - Вставьте в редактор GitHub
   - Нажмите "Commit changes"
