✅ ЧТО РЕАЛИЗОВАНО:

1. Serverless функция (api/send-email.js) - отправка через SMTP
2. Поддержка вложений (Word файл отправляется вместе с письмом)
3. Практически неограниченное количество писем
4. Бесплатно через Vercel/Netlify

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 ЧТО НУЖНО СДЕЛАТЬ:

1️⃣  ПОДГОТОВКА GMAIL/YANDEX SMTP

   Gmail:
   → https://myaccount.google.com/apppasswords
   → Создайте пароль приложения для "Mail"
   → ✅ Скопируйте пароль (16 символов)

   Yandex:
   → https://passport.yandex.ru/profile → Безопасность
   → Создайте пароль приложения
   → ✅ Скопируйте пароль

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2️⃣  ДЕПЛОЙ НА VERCEL (РЕКОМЕНДУЕТСЯ)

   Вариант A: Через GitHub
   → Загрузите проект в GitHub
   → https://vercel.com → Import Project
   → Выберите репозиторий
   → Vercel автоматически определит настройки

   Вариант B: Через Vercel CLI
   → npm install -g vercel
   → vercel login
   → vercel (в папке проекта)
   → vercel --prod (для продакшна)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3️⃣  НАСТРОЙКА ПЕРЕМЕННЫХ ОКРУЖЕНИЯ

   Vercel → Settings → Environment Variables → Add:

   SMTP_HOST=smtp.gmail.com          (или smtp.yandex.ru)
   SMTP_PORT=587                      (или 465 для SSL)
   SMTP_SECURE=false                  (true для порта 465)
   SMTP_USER=ваш_email@gmail.com
   SMTP_PASSWORD=пароль_приложения   (из шага 1)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4️⃣  ОБНОВЛЕНИЕ КОДА (если нужно указать URL вручную)

   В deepseek_htmlобщая.html найдите createWordDocumentAndSend
   и используйте:

   emailService.sendApplicationEmailWithAttachment(
       blob, 
       formData, 
       applicationId, 
       'pendeho098rus@yandex.ru',
       'https://ваш-домен.vercel.app/api/send-email'
   )

   Или оставьте null - будет использован автоматический URL
