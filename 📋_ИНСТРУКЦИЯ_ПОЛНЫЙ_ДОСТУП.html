🔑 Настройка полного доступа к GitHub

СПОСОБ 1: Установить GitHub CLI (РЕКОМЕНДУЕТСЯ) ⭐

Это даст мне возможность использовать команды напрямую!

ШАГ 1: Установка

Дважды кликните на файл: 🚀_УСТАНОВИТЬ_GITHUB_CLI.bat

Или выполните в командной строке:

winget install --id GitHub.cli

ШАГ 2: Авторизация

После установки выполните:

gh auth login

Выберите:

  • GitHub.com
  • HTTPS
  • Authenticate Git with your GitHub credentials? Yes
  • Login with a web browser? Yes

Нажмите Enter, откроется браузер для авторизации.

ШАГ 3: Проверка

Выполните:

gh repo view volkonskiy93-cyber/-2

Если видите информацию о репозитории - всё работает!

СПОСОБ 2: Улучшить токен доступа

Создайте новый токен с полными правами:

ШАГ 1: Создание токена

1. Откройте: https://github.com/settings/tokens/new

2. Название: "Полный доступ для автоматизации"

3. Срок: "No expiration"

4. Выберите ВСЕ права:

  • ✅ repo (полный доступ к репозиториям)
  • ✅ workflow (для GitHub Actions)
  • ✅ admin:repo_hook (для веб-хуков)

5. Нажмите "Generate token"

6. Скопируйте токен и сообщите мне
