✅ Система теперь использует шаблоны Excel файлов для сохранения форматирования!

═══════════════════════════════════════════════════════════════
📁 РАСПОЛОЖЕНИЕ ШАБЛОНОВ
═══════════════════════════════════════════════════════════════

Шаблоны должны находиться в той же папке, что и HTML файл:

✅ Заявка ФИГАРО.xlsx
✅ Заявка ТТК.xlsx

═══════════════════════════════════════════════════════════════
🔧 КАК ЭТО РАБОТАЕТ
═══════════════════════════════════════════════════════════════

1. Система пытается загрузить шаблон Excel файла
2. Если шаблон найден:
   ✅ Загружает его со всеми стилями и форматированием
   ✅ Заполняет данными из формы
   ✅ Сохраняет все форматирование (шрифты, цвета, границы, объединение ячеек)
   
3. Если шаблон не найден:
   ✅ Создает новый файл с базовым форматированием
   ✅ Заполняет данными из формы

═══════════════════════════════════════════════════════════════
⚠️ ВАЖНО ДЛЯ РАБОТЫ ЧЕРЕЗ ВЕБ-СЕРВЕР
═══════════════════════════════════════════════════════════════

Для работы шаблонов через веб-сервер (GitHub Pages, Vercel и т.д.):

1. Загрузите файлы шаблонов в ту же папку, что и HTML файл:
   - Заявка ФИГАРО.xlsx
   - Заявка ТТК.xlsx

2. Убедитесь, что файлы доступны по URL:
   - https://ваш-сайт.com/Заявка ФИГАРО.xlsx
   - https://ваш-сайт.com/Заявка ТТК.xlsx

3. Если используете GitHub Pages:
   ✅ Загрузите файлы в корень репозитория
   ✅ Или в ту же папку, где находится HTML файл

═══════════════════════════════════════════════════════════════
🧪 ТЕСТИРОВАНИЕ
═══════════════════════════════════════════════════════════════

1. Откройте файл deepseek_htmlобщая.html в браузере
2. Заполните форму ФИГАРО или ТТК
3. Нажмите "Отправить заявку"
4. Проверьте созданный Excel файл:
   ✅ Должен иметь такое же форматирование, как шаблон
   ✅ Все данные должны быть заполнены
   ✅ Оборудование должно быть в правильных столбцах

═══════════════════════════════════════════════════════════════
💡 ПРИМЕЧАНИЕ О ФОРМАТИРОВАНИИ
═══════════════════════════════════════════════════════════════

SheetJS (библиотека для работы с Excel) имеет некоторые ограничения:
- ✅ Может читать стили из шаблона
- ✅ Может сохранять базовое форматирование
- ⚠️ Некоторые сложные стили могут не сохраниться полностью

Для полного сохранения всех стилей (особенно сложных) может потребоваться:
- Использование серверной обработки
- Или использование более продвинутых библиотек

Но для большинства случаев текущая реализация должна работать хорошо!

═══════════════════════════════════════════════════════════════
🔍 ПРОВЕРКА РАБОТЫ ШАБЛОНОВ
═══════════════════════════════════════════════════════════════

Если шаблоны не загружаются:

1. Проверьте консоль браузера (F12) на ошибки
2. Убедитесь, что файлы находятся в правильной папке
3. Проверьте, что файлы доступны через веб-сервер
4. Если используете file:// протокол, шаблоны могут не загрузиться
   → Используйте веб-сервер (например, через VS Code Live Server)
