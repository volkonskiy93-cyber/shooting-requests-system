  КОМАНДЫ ДЛЯ БЫСТРОЙ ЗАГРУЗКИ НА VERCEL
═══════════════════════════════════════════════════════════════

Выполните эти команды по порядку в PowerShell:

───────────────────────────────────────────────────────────────
ШАГ 1: Установка Vercel CLI (если еще не установлен)
───────────────────────────────────────────────────────────────

npm install -g vercel

───────────────────────────────────────────────────────────────
ШАГ 2: Вход в Vercel
───────────────────────────────────────────────────────────────

vercel login

(В браузере откроется окно - войдите в Vercel)

───────────────────────────────────────────────────────────────
ШАГ 3: Переход в папку проекта
───────────────────────────────────────────────────────────────

cd "c:\Исходники DaVinci\дут"

───────────────────────────────────────────────────────────────
ШАГ 4: Деплой проекта
───────────────────────────────────────────────────────────────

vercel

(Следуйте инструкциям на экране - нажимайте Enter для подтверждения)

───────────────────────────────────────────────────────────────
ШАГ 5: Деплой в продакшн
───────────────────────────────────────────────────────────────

vercel --prod

───────────────────────────────────────────────────────────────
✅ ГОТОВО!
───────────────────────────────────────────────────────────────

После этого:
1. Откройте панель Vercel: https://vercel.com
2. Найдите ваш проект
3. Перейдите к ШАГУ 4 из файла VERCEL_НАСТРОЙКА_ШАГ_ЗА_ШАГОМ.txt
   (настройка переменных окружения)
