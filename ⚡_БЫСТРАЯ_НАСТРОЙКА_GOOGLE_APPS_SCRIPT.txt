✅ ПРЕИМУЩЕСТВА:
   - Абсолютно бесплатно

   - Работает через Gmail

═══════════════════════════════════════════════════════════════
📋 ШАГ 1: СОЗДАНИЕ GOOGLE APPS SCRIPT (2 минуты)
═══════════════════════════════════════════════════════════════

1. Откройте: https://script.google.com
2. Нажмите "Новый проект"
3. Удалите весь код в редакторе
4. Откройте файл: google-apps-script.js
5. Скопируйте ВЕСЬ код из файла
6. Вставьте в редактор Google Apps Script
7. Сохраните (Ctrl+S) - назовите "Отправка заявок"

═══════════════════════════════════════════════════════════════
📋 ШАГ 2: РАЗВЕРТЫВАНИЕ (2 минуты)
═══════════════════════════════════════════════════════════════

1. В редакторе нажмите "Развернуть" → "Новое развертывание"
2. Нажмите на значок шестеренки ⚙️ рядом с "Тип развертывания"
3. Выберите "Веб-приложение"
4. Заполните:
   - Описание: "Отправка заявок на съемку"
   - Выполнять от имени: "Меня"
   - У кого есть доступ: "Все"
5. Нажмите "Развернуть"

⚠️ ВАЖНО: При первом развертывании Google попросит авторизоваться:
   - Нажмите "Разрешить"
   - Выберите ваш Google аккаунт
   - Нажмите "Дополнительно" → "Перейти к [название проекта] (небезопасно)"
   - Нажмите "Разрешить"

6. Скопируйте URL веб-приложения (он будет показан)
   Пример: https://script.google.com/macros/s/AKfycby.../exec

═══════════════════════════════════════════════════════════════
📋 ШАГ 3: НАСТРОЙКА САЙТА (1 минута)
═══════════════════════════════════════════════════════════════

1. Откройте файл: email-service.js
2. Найдите строку:
   this.googleAppsScriptUrl = null;
3. Замените на:
   this.googleAppsScriptUrl = 'ВАШ_URL_ИЗ_ШАГА_2';
   (Вставьте URL, который скопировали в шаге 2)

4. Сохраните файл

═══════════════════════════════════════════════════════════════
📋 ШАГ 4: ОБНОВЛЕНИЕ КОДА ОТПРАВКИ (опционально)
═══════════════════════════════════════════════════════════════

Откройте файл: deepseek_htmlобщая.html

Найдите строку (около строки 1951):
   emailService.sendApplicationEmailWithAttachment(...)

Замените на:
   emailService.sendViaGoogleAppsScript(...)

Или оставьте как есть - код автоматически попробует Google Apps Script,
если serverless функция не работает.

🐛 ЕСЛИ НЕ РАБОТАЕТ:
═══════════════════════════════════════════════════════════════

1. Проверьте, что URL правильный (скопирован полностью)
2. Проверьте, что развертывание сделано с доступом "Все"
3. Проверьте консоль браузера (F12) на ошибки
4. Проверьте логи в Google Apps Script:
   → script.google.com → Ваш проект → Выполнения
