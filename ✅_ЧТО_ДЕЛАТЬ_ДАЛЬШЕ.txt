📋 ШАГ 1: ЗАПУСТИТЬ БОТА
─────────────────────────────────────────────────────────────
Если бот еще не запущен:
    → Дважды кликните на файл: ЗАПУСТИТЬ_БОТА.bat

Вы должны увидеть в окне:
    🤖 Телеграм бот запущен!
    ✅ Бот готов к работе!
    📋 Текущее количество получателей: 0

Оставьте это окно открытым - бот должен работать постоянно!

─────────────────────────────────────────────────────────────

📱 ШАГ 2: НАЙТИ БОТА В TELEGRAM
─────────────────────────────────────────────────────────────
1. Откройте Telegram на телефоне или компьютере
2. Найдите вашего бота по username (который вы указали при создании)
   ИЛИ
3. Найдите бота через @BotFather:
   - Откройте @BotFather
   - Отправьте /mybots
   - Выберите вашего бота
   - Нажмите "Open Bot"

─────────────────────────────────────────────────────────────

💬 ШАГ 3: ПЕРВЫЙ КОНТАКТ С БОТОМ
─────────────────────────────────────────────────────────────
1. Откройте чат с ботом
2. Отправьте команду: /start
3. Бот ответит приветствием и списком команд

─────────────────────────────────────────────────────────────

👥 ШАГ 4: ДОБАВИТЬ ПОЛУЧАТЕЛЕЙ
─────────────────────────────────────────────────────────────

ВАРИАНТ А: Добавить себя (для теста)
─────────────────────────────────────
1. В чате с ботом отправьте: /add
2. Бот ответит: "✅ Ваш чат добавлен в список получателей!"

ВАРИАНТ Б: Добавить других людей
─────────────────────────────────
1. Попросите каждого человека:
   - Найти вашего бота в Telegram
   - Отправить боту команду: /start
   - Отправить боту команду: /add
2. Бот добавит их чат в список получателей

Проверить список получателей:
    → Отправьте боту: /list

─────────────────────────────────────────────────────────────

📤 ШАГ 5: ОТПРАВИТЬ ПЕРВУЮ РАССЫЛКУ
─────────────────────────────────────────────────────────────
1. В чате с ботом отправьте:
   /broadcast Привет! Это тестовая рассылка.

2. Бот ответит:
   📤 Начинаю рассылку сообщения X получателям...
   ✅ Рассылка завершена!
   ✅ Успешно: X
   ❌ Ошибок: 0

─────────────────────────────────────────────────────────────

🧪 ШАГ 6: ПРОТЕСТИРОВАТЬ
─────────────────────────────────────────────────────────────
1. Добавьте себя в получатели: /add
2. Отправьте тестовое сообщение: /test
3. Вы должны получить сообщение от бота
4. Отправьте рассылку: /broadcast Тест
5. Проверьте, что сообщение пришло

─────────────────────────────────────────────────────────────

📋 ПОЛЕЗНЫЕ КОМАНДЫ
─────────────────────────────────────────────────────────────
/start      - Начать работу с ботом
/help       - Показать справку
/add        - Добавить чат в список получателей
/remove     - Удалить чат из списка
/list       - Показать список получателей
/broadcast  - Отправить рассылку всем
/test       - Тестовое сообщение себе
