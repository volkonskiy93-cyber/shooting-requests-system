ШАГ 1: ЗАГРУЗИТЕ ФАЙЛЫ (СДЕЛАЙТЕ ЭТО ПЕРВЫМ!)
───────────────────────────────────────────────────────
1. Перейдите на: https://github.com/volkonskiy93-cyber/-2
2. Нажмите: "uploading an existing file"
3. Загрузите файлы:
   - index.html
   - deepseek_htmlобщая.html
   - admin.html
   - admin.js
   - data.js
   - .nojekyll
4. Commit message: "Initial commit"
5. Нажмите: "Commit changes"
6. Подождите, пока файлы загрузятся

ШАГ 2: ВКЛЮЧИТЕ PAGES (ТОЛЬКО ПОСЛЕ ШАГА 1!)
───────────────────────────────────────────────────────
1. Перейдите: Settings → Pages
2. Branch: выберите "main" (если нет - попробуйте "master")
3. Folder: выберите "/ (root)"
4. Теперь кнопка Save должна стать активной!
5. Нажмите Save

ШАГ 3: ПРОВЕРЬТЕ ССЫЛКУ
───────────────────────────────────────────────────────
Через 1-2 минуты ссылка будет:
https://volkonskiy93-cyber.github.io/-2/
