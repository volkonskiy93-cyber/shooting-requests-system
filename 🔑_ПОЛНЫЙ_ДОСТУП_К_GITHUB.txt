ВАРИАНТ 1: УСТАНОВИТЬ GITHUB CLI (gh) - РЕКОМЕНДУЕТСЯ ⭐
═══════════════════════════════════════════════════════════════

Это даст мне возможность использовать команды напрямую!

ШАГ 1: Установите GitHub CLI
──────────────────────────────
1. Скачайте: https://cli.github.com/
2. Или через winget:
   winget install --id GitHub.cli
3. Или через Chocolatey:
   choco install gh

ШАГ 2: Авторизуйтесь
────────────────────
1. Откройте командную строку или PowerShell
2. Выполните:
   gh auth login
3. Выберите:
   - GitHub.com
   - HTTPS
   - Authenticate Git with your GitHub credentials? Yes
   - Login with a web browser? Yes
4. Нажмите Enter, откроется браузер
5. Авторизуйтесь в браузере
6. Вернитесь в терминал - готово!

ШАГ 3: Проверьте доступ
────────────────────────
Выполните:
   gh repo view volkonskiy93-cyber/-2

Если видите информацию о репозитории - всё работает!

ВАРИАНТ 2: УЛУЧШИТЬ ТОКЕН ДОСТУПА
═══════════════════════════════════════════════════════════════

ШАГ 1: Создайте новый токен с полными правами
───────────────────────────────────────────────
1. Откройте: https://github.com/settings/tokens/new
2. Название: "Полный доступ для автоматизации"
3. Срок: "No expiration" (или 90 days)
4. Выберите ВСЕ права (scopes):
   ✅ repo (полный доступ к репозиториям)
   ✅ workflow (для GitHub Actions)
   ✅ admin:repo_hook (для веб-хуков)
   ✅ admin:org (если нужно управление организацией)
   ✅ delete_repo (если нужно удаление)
5. Нажмите "Generate token"
6. Скопируйте токен (показывается только один раз!)

ШАГ 2: Сообщите мне новый токен
─────────────────────────────────
Я обновлю все скрипты с новым токеном

ВАРИАНТ 3: СОЗДАТЬ GITHUB APP
═══════════════════════════════════════════════════════════════

Для максимального контроля:

1. Откройте: https://github.com/settings/apps/new
2. Заполните форму:
   - GitHub App name: "Автоматизация проекта"
   - Homepage URL: https://github.com/volkonskiy93-cyber/-2
   - Webhook URL: можно оставить пустым
   - Permissions: выберите нужные права
3. Установите приложение в ваш репозиторий
4. Предоставьте мне Client ID и Client Secret
