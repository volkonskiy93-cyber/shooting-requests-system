Структура таблицы оборудования:
┌─────────────────────────────────────────────────────────────┐
│ Основной комплект        │ Дополнительное │ Выбор доп.      │
│                          │ оборудование   │ оборудования    │
├──────────────────────────┼────────────────┼─────────────────┤
│ Название + [количество]  │ Название       │ [0-3]          │
└──────────────────────────┴────────────────┴─────────────────┘

При сохранении заявки система собирает:
- main: название основного оборудования
- mainQuantity: количество основного оборудования
- additional: название дополнительного оборудования
- additionalQuantity: количество дополнительного оборудования
