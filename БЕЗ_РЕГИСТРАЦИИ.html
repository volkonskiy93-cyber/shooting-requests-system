Вариант 2: Surge.sh (БЕЗ регистрации при установке)

Самый простой способ через командную строку:

  1. Откройте PowerShell в папке проекта
  2. Выполните: npm install -g surge
  3. Затем: surge
  4. Следуйте инструкциям (создаст аккаунт автоматически)
⚠️ Требует Node.js. Если нет - используйте другие варианты.

✅ РЕКОМЕНДАЦИЯ

Попробуйте Netlify в режиме инкогнито:

  1. Откройте браузер в режиме инкогнито (Ctrl+Shift+N)
  2. Перейдите на: https://app.netlify.com/drop
  3. Перетащите файлы - обычно там не просят пароль

Или: Просто зарегистрируйтесь на Netlify (это займет 30 секунд через Google) - это бесплатно и дает много возможностей!
