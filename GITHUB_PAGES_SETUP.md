# Настройка GitHub Pages за 5 минут

## Шаг 1: Создайте репозиторий на GitHub

1. Перейдите на https://github.com/new
2. Название репозитория: `shooting-applications` (или любое другое)
3. Выберите **Public** (публичный)
4. НЕ ставьте галочки (README, .gitignore, license)
5. Нажмите **"Create repository"**

## Шаг 2: Загрузите файлы через веб-интерфейс

1. На странице нового репозитория нажмите **"uploading an existing file"**
2. Откройте папку `c:\Users\user\Desktop\дут`
3. Перетащите ВСЕ эти файлы в GitHub:
   - ✅ index.html
   - ✅ deepseek_htmlобщая.html
   - ✅ admin.html
   - ✅ admin.js
   - ✅ data.js
4. Внизу страницы в поле "Commit message" напишите: `Initial commit`
5. Нажмите **"Commit changes"**

## Шаг 3: Включите GitHub Pages

1. В репозитории перейдите в **Settings** (вверху справа)
2. В меню слева найдите **Pages**
3. В разделе "Source" выберите:
   - Branch: **main** (или master)
   - Folder: **/ (root)**
4. Нажмите **Save**

## Шаг 4: Получите ссылку

Через 1-2 минуты ваш сайт будет доступен по адресу:
```
https://ваш-username.github.io/shooting-applications/
```

Замените `ваш-username` на ваш GitHub username!
