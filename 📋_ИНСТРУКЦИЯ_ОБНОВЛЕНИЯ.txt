Проблема "Failed to fetch" возникает из-за CORS при открытии файла 
через file:// протокол. Используйте один из способов ниже:

═══════════════════════════════════════════════════════════════
СПОСОБ 1: Через локальный веб-сервер (РЕКОМЕНДУЕТСЯ)
═══════════════════════════════════════════════════════════════

1. Откройте командную строку или PowerShell в папке с файлами
2. Запустите локальный веб-сервер:

   Python 3:
   python -m http.server 8000

   Или Python 2:
   python -m SimpleHTTPServer 8000

   Или Node.js:
   npx http-server -p 8000

3. Откройте в браузере:
   http://localhost:8000/🚀_ОБНОВИТЬ_GITHUB_СЕЙЧАС.html

4. Файлы автоматически обновятся на GitHub

═══════════════════════════════════════════════════════════════
СПОСОБ 2: Через PowerShell скрипт
═══════════════════════════════════════════════════════════════

1. Откройте PowerShell в папке с файлами
2. Выполните команду:
   
   Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
   .\update_github_simple.ps1

═══════════════════════════════════════════════════════════════
СПОСОБ 3: Ручное обновление через GitHub веб-интерфейс
═══════════════════════════════════════════════════════════════

1. Откройте: https://github.com/volkonskiy93-cyber/-2
2. Для каждого файла (index.html, deepseek_htmlобщая.html, admin.html):
   - Нажмите на файл
   - Нажмите кнопку "✏️ Edit" (карандаш)
   - Скопируйте содержимое локального файла
   - Вставьте в редактор GitHub
   - Нажмите "Commit changes"

═══════════════════════════════════════════════════════════════
СПОСОБ 4: Использовать GitHub Desktop
═══════════════════════════════════════════════════════════════

1. Установите GitHub Desktop: https://desktop.github.com/
2. Откройте репозиторий: volkonskiy93-cyber/-2
3. Скопируйте обновленные файлы в папку репозитория
4. В GitHub Desktop нажмите "Commit" и "Push"
