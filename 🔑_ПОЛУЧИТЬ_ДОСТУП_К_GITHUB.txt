Для автоматического обновления файлов на GitHub нужен токен доступа.

═══════════════════════════════════════════════════════════════
📋 ШАГ 1: СОЗДАНИЕ ТОКЕНА ДОСТУПА GITHUB
═══════════════════════════════════════════════════════════════

1. Откройте: https://github.com/settings/tokens
2. Нажмите "Generate new token" → "Generate new token (classic)"
3. Название токена: "Обновление проекта"
4. Выберите срок действия: "90 days" (или "No expiration")
5. Выберите права (scopes):
   ✅ repo (полный доступ к репозиториям)
   ✅ workflow (для GitHub Actions, если нужно)
6. Нажмите "Generate token" внизу
7. ⚠️ ВАЖНО: Скопируйте токен СРАЗУ! Он показывается только один раз!
   Токен будет выглядеть так: ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

═══════════════════════════════════════════════════════════════
📋 ШАГ 2: СОХРАНИТЕ ТОКЕН БЕЗОПАСНО
═══════════════════════════════════════════════════════════════

Создайте файл: github_token.txt
Сохраните в него токен (только токен, без лишнего текста)

⚠️ НЕ ЗАГРУЖАЙТЕ ЭТОТ ФАЙЛ НА GITHUB!
⚠️ ДЕРЖИТЕ ТОКЕН В СЕКРЕТЕ!

═══════════════════════════════════════════════════════════════
📋 ШАГ 3: ИСПОЛЬЗОВАНИЕ ТОКЕНА
═══════════════════════════════════════════════════════════════

После создания токена я смогу:
✅ Автоматически обновлять файлы на GitHub
✅ Загружать новые версии файлов
✅ Синхронизировать локальные изменения с GitHub

═══════════════════════════════════════════════════════════════
