═══════════════════════════════════════════════════════════════
📋 КАК ЭТО РАБОТАЕТ
═══════════════════════════════════════════════════════════════

1. Пользователь заполняет форму заявки ФИГАРО или ТТК
2. Нажимает кнопку "Отправить заявку"
3. Система автоматически:
   ✅ Создает Excel файл (.xlsx) с данными заявки
   ✅ Скачивает файл в папку "Загрузки"
   ✅ Показывает модальное окно с инструкциями
   ✅ Пытается отправить файл на почту автоматически

4. Пользователь:
   ✅ Нажимает "Открыть почтовый клиент" (если автоматическая отправка не сработала)
   ✅ Прикрепляет Excel файл к письму
   ✅ Нажимает "Отправить"

═══════════════════════════════════════════════════════════════
📊 СТРУКТУРА EXCEL ФАЙЛА
═══════════════════════════════════════════════════════════════

Excel файл создается со следующей структурой:

ФИГАРО:
- Заголовок: "Заявка на видеосъемку - ВЕК XXL (ФИГАРО)"
- Программа: "Доброе утро"
- Все поля заявки в формате "Поле: Значение"
- Таблица оборудования с двумя столбцами:
  * Основной комплект
  * Дополнительное оборудование

ТТК:
- Заголовок: "Заявка на видеосъемку - Технологический центр ТВ (ТТК)"
- Программа: "Доброе утро"
- Все поля заявки в формате "Поле: Значение"
- Таблица оборудования с двумя столбцами:
  * Основной комплект
  * Дополнительное оборудование
