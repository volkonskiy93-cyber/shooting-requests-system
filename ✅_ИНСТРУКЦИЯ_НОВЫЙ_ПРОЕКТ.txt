После создания репозитория GitHub покажет инструкции.

Используйте один из способов:

ВАРИАНТ А: Через веб-интерфейс GitHub
───────────────────────────────────────────────────────────────
Для каждого файла:
1. Нажмите "Add file" → "Create new file"
2. Имя файла: (например, index.html)
3. Скопируйте содержимое из локального файла
4. Вставьте в редактор
5. "Commit new file"

═══════════════════════════════════════════════════════════════
ШАГ 3: НАСТРОЙКА VERCEL
═══════════════════════════════════════════════════════════════

1. Откройте: https://vercel.com/dashboard
2. Нажмите "Add New Project"
3. Выберите "Import Git Repository"
4. Найдите репозиторий: shooting-requests-system
5. Нажмите "Import"
6. Framework Preset: Other
7. Root Directory: ./
8. Build Command: (оставьте пустым)
9. Output Directory: ./
10. Install Command: npm install (если нужно)
11. Нажмите "Deploy"
