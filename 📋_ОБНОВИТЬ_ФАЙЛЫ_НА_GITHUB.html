📋 Обновление файлов на GitHub

📝 Инструкция:

  1. Откройте файл на GitHub (ссылка ниже)
  2. Нажмите "Edit this file" (карандаш)
  3. Нажмите кнопку "Скопировать содержимое" ниже
  4. В GitHub редакторе выделите всё (Ctrl+A) и вставьте (Ctrl+V)
  5. Внизу напишите: "Обновление стилей iOS 26"
  6. Нажмите "Commit changes"
