═══════════════════════════════════════════════════════════════

2. Ваш проект → Settings → Environment Variables

═══════════════════════════════════════════════════════════════
🔄 ШАГ 2: ОБЯЗАТЕЛЬНО СДЕЛАЙТЕ REDEPLOY
═══════════════════════════════════════════════════════════════

После добавления/изменения переменных окружения ОБЯЗАТЕЛЬНО:

1. Перейдите: Deployments
2. Найдите ПОСЛЕДНИЙ деплой (самый верхний в списке)
3. Нажмите "..." (три точки) справа от деплоя
4. Выберите "Redeploy"
5. Подтвердите

ИЛИ:

1. Перейдите: Deployments
2. Нажмите "Create Deployment" или "Redeploy" в меню проекта
3. Выберите последний коммит
4. Подтвердите

⚠️ БЕЗ REDEPLOY переменные окружения НЕ применятся!

🧪 ШАГ 3: ПРОВЕРЬТЕ РАБОТУ ФУНКЦИИ

После redeploy подождите 1-2 минуты и проверьте:

3. Создайте тестовую заявку (любого типа)

═══════════════════════════════════════════════════════════════
🐛 ЕСЛИ НЕ РАБОТАЕТ - ДИАГНОСТИКА
═══════════════════════════════════════════════════════════════

1. Откройте консоль браузера (F12 → Console)
   → Посмотрите, есть ли ошибки при отправке

2. Проверьте логи в Vercel:
   → Deployments → Последний деплой → Functions → api/send-email
   → Посмотрите логи выполнения функции

3. Проверьте переменные окружения еще раз:
   → Убедитесь, что SMTP_PASSWORD правильный (пароль приложения Yandex, не основной пароль!)

4. Проверьте, что функция доступна:
   → Откройте: https://2-git-main-pendehos-projects.vercel.app/api/send-email
   → Должна быть ошибка "Method not allowed" (это нормально для GET запроса)
   → Если ошибка другая - функция не задеплоена

═══════════════════════════════════════════════════════════════
📧 ПРОВЕРКА ПАРОЛЯ ПРИЛОЖЕНИЯ YANDEX
═══════════════════════════════════════════════════════════════

Если письма не отправляются, возможно проблема с паролем:

1. Откройте: https://id.yandex.ru/security
2. Войдите в аккаунт Volkonskiyser@yandex.ru
3. Раздел "Пароли приложений"
4. Создайте новый пароль приложения (если нет)
5. Скопируйте пароль (он будет показан только один раз!)
6. Обновите переменную SMTP_PASSWORD в Vercel этим паролем
7. Сделайте Redeploy

⚠️ ВАЖНО: Используйте ПАРОЛЬ ПРИЛОЖЕНИЯ, а не основной пароль аккаунта!
