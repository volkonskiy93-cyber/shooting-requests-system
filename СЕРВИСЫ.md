# Доступные сервисы для размещения проекта

## ✅ Рекомендуемые бесплатные сервисы:

### 1. **Netlify Drop** ⭐ САМЫЙ ПРОСТОЙ
- **URL:** https://app.netlify.com/drop
- **Особенности:**
  - Не требует регистрации для загрузки
  - Просто перетащите папку
  - Мгновенная ссылка
  - Бесплатный SSL сертификат
- **Ограничения:** Нет

### 2. **Surge.sh** (через командную строку)
- **URL:** https://surge.sh/
- **Особенности:**
  - Очень быстрая загрузка через терминал
  - Бесплатный поддомен
  - Работает сразу после установки
- **Требует:** Node.js и npm

### 3. **GitHub Pages**
- **URL:** https://pages.github.com/
- **Особенности:**
  - Интеграция с Git
  - Надежный хостинг от GitHub
  - Можно использовать свой домен
- **Требует:** GitHub аккаунт

### 4. **Vercel**
- **URL:** https://vercel.com/
- **Особенности:**
  - Автоматический деплой
  - Отличная производительность
  - Поддержка доменов
- **Требует:** Регистрацию

### 5. **Firebase Hosting**
- **URL:** https://firebase.google.com/
- **Особенности:**
  - От Google
  - CDN по всему миру
  - 10 GB бесплатно
- **Требует:** Google аккаунт
