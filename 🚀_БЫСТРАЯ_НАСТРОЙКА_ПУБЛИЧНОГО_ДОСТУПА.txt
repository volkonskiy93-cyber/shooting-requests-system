═══════════════════════════════════════════════════════════════
📋 ПОШАГОВАЯ ИНСТРУКЦИЯ (5 МИНУТ)
═══════════════════════════════════════════════════════════════

ШАГ 1: Откройте ваш репозиторий на GitHub
───────────────────────────────────────────
→ https://github.com/volkonskiy93-cyber/-2

ШАГ 2: Перейдите в Settings
─────────────────────────────
→ Нажмите на вкладку "Settings" вверху репозитория
→ Или перейдите напрямую:
   https://github.com/volkonskiy93-cyber/-2/settings

ШАГ 3: Найдите раздел "Pages"
───────────────────────────────
→ В меню слева прокрутите вниз
→ Найдите раздел "Pages" (в секции "Code and automation")
→ Или перейдите напрямую:
   https://github.com/volkonskiy93-cyber/-2/settings/pages

ШАГ 4: Настройте GitHub Pages
──────────────────────────────
→ В разделе "Source" выберите:
   • Branch: main (или master, если main нет)
   • Folder: / (root)
→ Нажмите "Save"

ШАГ 5: Подождите 1-2 минуты
───────────────────────────
→ GitHub обработает настройки
→ Появится сообщение: "Your site is published at..."

ШАГ 6: Получите публичную ссылку
─────────────────────────────────
→ После настройки GitHub покажет ссылку:
   https://volkonskiy93-cyber.github.io/-2/

✅ ГОТОВО! Проект будет доступен по этой ссылке для ВСЕХ!

⚠️ ВАЖНО: ЕСЛИ КНОПКА SAVE НЕ АКТИВНА
═══════════════════════════════════════════════════════════════

Это означает, что в репозитории нет файлов или нет ветки main/master.

Решение:
1. Убедитесь, что файлы загружены в репозиторий
2. Проверьте, какая ветка у вас есть (main или master)
3. Если ветки нет - создайте коммит с любым файлом
