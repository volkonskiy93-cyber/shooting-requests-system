      http://localhost:5000
   
   3. Зарегистрируйтесь:
      - Введите email
      - Придумайте пароль (минимум 4 символа)
      - Подтвердите пароль
   
   4. Выберите роль:
      - Корреспондент (создание заявок)
      - Координатор (просмотр всех заявок)
   
   5. Создайте свою первую заявку!

⚠️ Если приложение не открывается:

   1. Проверьте, запущено ли приложение:
      - Должно быть открыто окно Python с логами
      - Должно быть сообщение "Запуск сервера на http://localhost:5000"
   
   2. Если порт 5000 занят:
      - Закройте другие приложения, использующие порт 5000
      - Или измените порт в файле run.py (строка 14)
   
   3. Проверьте, что все зависимости установлены:
      python -m pip install -r requirements.txt
   
   4. Если есть ошибки:
      - Посмотрите на вывод в окне Python
      - Проверьте, что файл .env создан
