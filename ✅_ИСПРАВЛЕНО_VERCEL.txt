ПРОБЛЕМА: "Function Runtimes must have a valid version"
───────────────────────────────────────────────────────────────
В файле vercel.json была неправильная конфигурация runtime
для serverless функций.

РЕШЕНИЕ: Удалена секция functions из vercel.json
───────────────────────────────────────────────────────────────
Vercel автоматически определит runtime для файлов в папке api/,
поэтому явное указание runtime не требуется.

═══════════════════════════════════════════════════════════════

БЫЛО:

    "api/send-email.js": {
      "runtime": "nodejs18.x"  ← Неправильный формат
    }
  }

СТАЛО:
  (секция functions удалена - Vercel определит автоматически)
