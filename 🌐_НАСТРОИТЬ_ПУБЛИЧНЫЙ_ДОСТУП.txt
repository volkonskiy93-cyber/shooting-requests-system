Проблема: Vercel требует авторизацию
Решение: Использовать GitHub Pages (полностью публичный доступ)

═══════════════════════════════════════════════════════════════
ШАГ 1: СДЕЛАТЬ РЕПОЗИТОРИЙ ПУБЛИЧНЫМ
═══════════════════════════════════════════════════════════════

1. Откройте: https://github.com/volkonskiy93-cyber/-2/settings

2. Прокрутите вниз до раздела "Danger Zone"

3. Нажмите "Change visibility"

4. Выберите "Make public"

5. Подтвердите действие

═══════════════════════════════════════════════════════════════
ШАГ 2: ВКЛЮЧИТЬ GITHUB PAGES
═══════════════════════════════════════════════════════════════

1. В том же разделе Settings откройте "Pages" (слева в меню)

2. В разделе "Source" выберите:
   - Branch: main (или master)
   - Folder: / (root)

3. Нажмите "Save"

4. Подождите 1-2 минуты

═══════════════════════════════════════════════════════════════
ШАГ 3: ПОЛУЧИТЬ ПУБЛИЧНУЮ ССЫЛКУ
═══════════════════════════════════════════════════════════════

После настройки GitHub Pages ваша ссылка будет:

https://volkonskiy93-cyber.github.io/-2/

ИЛИ

https://volkonskiy93-cyber.github.io/-2/index.html

═══════════════════════════════════════════════════════════════
ШАГ 4: ПРОВЕРИТЬ РАБОТУ
═══════════════════════════════════════════════════════════════

1. Откройте ссылку в режиме инкогнито (чтобы проверить без авторизации)

2. Страница должна открыться БЕЗ требования авторизации

3. Если всё работает - готово!

═══════════════════════════════════════════════════════════════
АЛЬТЕРНАТИВА: НАСТРОИТЬ VERCEL ДЛЯ ПУБЛИЧНОГО ДОСТУПА
═══════════════════════════════════════════════════════════════

Если хотите использовать Vercel:

1. Откройте: https://vercel.com/dashboard

2. Найдите проект "2" или "-2"

3. Откройте Settings проекта

4. В разделе "General" найдите "Visibility"

5. Убедитесь, что выбрано "Public" (не "Private")

6. Сохраните изменения
