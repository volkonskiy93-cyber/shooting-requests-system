  НАСТРОЙКА EmailJS - ЗАПОЛНИТЕ ЭТИ ЗНАЧЕНИЯ ПОСЛЕ РЕГИСТРАЦИИ
═══════════════════════════════════════════════════════════════

После настройки EmailJS (см. ИНСТРУКЦИЯ_EMAILJS.md), 
заполните эти значения и вставьте их в файл email-service.js:

───────────────────────────────────────────────────────────────
ШАГ 1: Service ID
───────────────────────────────────────────────────────────────
Откуда: EmailJS → Email Services → Service ID
Пример: service_abc12345
Ваше значение: _________________________________

───────────────────────────────────────────────────────────────
ШАГ 2: Template ID
───────────────────────────────────────────────────────────────
Откуда: EmailJS → Email Templates → Template ID
Пример: template_xyz78901
Ваше значение: _________________________________

───────────────────────────────────────────────────────────────
ШАГ 3: Public Key
───────────────────────────────────────────────────────────────
Откуда: EmailJS → Account → General → Public Key
Пример: abcdefghijklmnop
Ваше значение: _________________________________

───────────────────────────────────────────────────────────────
КАК ЗАПОЛНИТЬ:

1. Откройте файл: email-service.js
2. Найдите строки 8-12 (около строки с this.emailjsConfig)
3. Замените:
   - 'YOUR_SERVICE_ID'   → ваш Service ID из шага 1
   - 'YOUR_TEMPLATE_ID'  → ваш Template ID из шага 2
   - 'YOUR_PUBLIC_KEY'   → ваш Public Key из шага 3
4. Сохраните файл

───────────────────────────────────────────────────────────────
ПРИМЕР ЗАПОЛНЕННОГО КОДА:

this.emailjsConfig = {
    serviceId: 'service_abc12345',      // ← Ваш Service ID
    templateId: 'template_xyz78901',    // ← Ваш Template ID
    publicKey: 'abcdefghijklmnop'       // ← Ваш Public Key
};

───────────────────────────────────────────────────────────────
ПОСЛЕ ЗАПОЛНЕНИЯ:
───────────────────────────────────────────────────────────────
✅ Проверьте, что файл сохранен
✅ Откройте index.html в браузере
✅ Создайте тестовую заявку
✅ Проверьте, что письмо отправляется
