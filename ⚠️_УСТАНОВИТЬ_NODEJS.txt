❌ ПРОБЛЕМА: Node.js не установлен!
─────────────────────────────────────────────────────────────

Node.js необходим для работы Telegram бота.

📥 КАК УСТАНОВИТЬ:
─────────────────────────────────────────────────────────────

ШАГ 1: СКАЧАТЬ NODE.JS
─────────────────────────────────────────────────────────────
1. Откройте браузер
2. Перейдите на: https://nodejs.org/
3. Скачайте версию LTS (рекомендуется)
   - Для Windows будет файл: node-vXX.X.X-x64.msi

ШАГ 2: УСТАНОВИТЬ
─────────────────────────────────────────────────────────────
1. Запустите скачанный файл .msi
2. Следуйте инструкциям установщика
3. Оставьте все настройки по умолчанию
4. Дождитесь завершения установки

ШАГ 3: ПЕРЕЗАГРУЗИТЬ КОМПЬЮТЕР
─────────────────────────────────────────────────────────────
После установки перезагрузите компьютер!

ШАГ 4: ПРОВЕРИТЬ УСТАНОВКУ
─────────────────────────────────────────────────────────────
1. Запустите файл: ПРОВЕРИТЬ_NODEJS.bat
2. Должно появиться:
   SUCCESS: Node.js is installed!
   vXX.X.X (версия Node.js)

ШАГ 5: ЗАПУСТИТЬ БОТА
─────────────────────────────────────────────────────────────
После успешной установки Node.js:
1. Запустите: ЗАПУСТИТЬ_БОТА.bat
2. Бот должен запуститься!

─────────────────────────────────────────────────────────────

🔗 ПРЯМАЯ ССЫЛКА ДЛЯ СКАЧИВАНИЯ:
─────────────────────────────────────────────────────────────
https://nodejs.org/dist/v20.11.0/node-v20.11.0-x64.msi

(Или зайдите на nodejs.org и скачайте последнюю LTS версию)

─────────────────────────────────────────────────────────────

💡 АЛЬТЕРНАТИВНЫЙ СПОСОБ (Через Chocolatey):
─────────────────────────────────────────────────────────────
Если у вас установлен Chocolatey:
    choco install nodejs

─────────────────────────────────────────────────────────────

❓ КАК ПРОВЕРИТЬ, ЧТО NODE.JS УСТАНОВЛЕН:
─────────────────────────────────────────────────────────────
1. Нажмите Windows + R
2. Введите: cmd
3. Нажмите Enter
4. Введите: node --version
5. Должна появиться версия (например: v20.11.0)

Если появляется ошибка "не является внутренней или внешней командой" - 
Node.js не установлен или не добавлен в PATH.
