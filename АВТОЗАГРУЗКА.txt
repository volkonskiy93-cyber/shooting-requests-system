ПРОСТОЙ СПОСОБ:

1. Откройте файл: ЗАГРУЗКА_НА_NETLIFY.html
   (двойной клик по файлу)

2. Нажмите кнопку "📤 Открыть Netlify Drop"

3. В окне браузера Netlify Drop откройте Проводник Windows
   (папку: c:\Users\user\Desktop\дут)

4. Выделите ВСЕ эти файлы:
   ✓ index.html
   ✓ deepseek_htmlобщая.html
   ✓ admin.html
   ✓ admin.js
   ✓ data.js

5. Перетащите эти 5 файлов в окно Netlify Drop

6. Готово! Получите ссылку вида:
   https://ваш-сайт.netlify.app
