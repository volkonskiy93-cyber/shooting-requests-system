ШАГ 1: Откройте страницу создания токена
───────────────────────────────────────────
→ https://github.com/settings/tokens/new

ШАГ 2: Заполните форму
───────────────────────
Note (название): Обновление проекта
Expiration (срок): 90 days (или No expiration)
Scopes (права): ✅ repo (поставьте галочку)

ШАГ 3: Создайте токен
──────────────────────
→ Прокрутите вниз
→ Нажмите "Generate token" (зеленая кнопка)

ШАГ 4: Скопируйте токен
────────────────────────
⚠️ ВАЖНО: Токен показывается ТОЛЬКО ОДИН РАЗ!
→ Скопируйте токен (он начинается с ghp_)
→ Выглядит так: ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

ШАГ 5: Используйте токен
─────────────────────────
→ Откройте файл: 🚀_АВТОМАТИЧЕСКОЕ_ОБНОВЛЕНИЕ_GITHUB.html
→ Вставьте токен в поле
→ Нажмите "Обновить все файлы на GitHub"

✅ ГОТОВО! Файлы будут автоматически обновлены!
