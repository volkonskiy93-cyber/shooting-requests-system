📋 ШАГ 1: СОЗДАНИЕ БОТА
─────────────────────────────────────────────────────────────
1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте: /newbot
4. Следуйте инструкциям
5. СОХРАНИТЕ ТОКЕН!

📦 ШАГ 2: УСТАНОВКА ЗАВИСИМОСТЕЙ
─────────────────────────────────────────────────────────────
Откройте терминал и выполните:
    npm install

🔑 ШАГ 3: НАСТРОЙКА ТОКЕНА
─────────────────────────────────────────────────────────────
Вариант А (рекомендуется):
1. Создайте файл .env в корне проекта
2. Добавьте строку:
   TELEGRAM_BOT_TOKEN=ваш_токен_здесь

Вариант Б:
1. Откройте bot_config.json
2. Добавьте токен в поле "token"

🚀 ШАГ 4: ЗАПУСК БОТА
─────────────────────────────────────────────────────────────
Выполните команду:
    npm run bot

Или:
    node bot.js

✅ ШАГ 5: ИСПОЛЬЗОВАНИЕ
─────────────────────────────────────────────────────────────
1. Найдите вашего бота в Telegram
2. Отправьте: /start
3. Добавьте получателей: /add
4. Отправьте рассылку: /broadcast Ваше сообщение

📖 ПОЛНАЯ ИНСТРУКЦИЯ
─────────────────────────────────────────────────────────────
Смотрите файл: 📱_ИНСТРУКЦИЯ_ТЕЛЕГРАМ_БОТА.md

💡 ОСНОВНЫЕ КОМАНДЫ
─────────────────────────────────────────────────────────────
/start      - Начать работу
/help       - Справка
/add        - Добавить чат в список получателей
/remove     - Удалить чат из списка
/list       - Показать список получателей
/broadcast  - Отправить рассылку
/test       - Тестовое сообщение
