# Инструкция по размещению проекта онлайн

## Вариант 1: Netlify (САМЫЙ ПРОСТОЙ) ⭐ РЕКОМЕНДУЕТСЯ

### Шаги:

1. **Перейдите на сайт Netlify:**
   - Откройте в браузере: https://www.netlify.com/
   - Нажмите "Sign up" (Регистрация) - можно через Google/GitHub/Email

2. **Загрузите файлы:**
   - После регистрации на главной странице найдите раздел "Want to deploy a new site without connecting to Git?"
   - Перетащите ВСЮ папку `дут` в окно "Drag & drop your site output folder here"
   - Или нажмите "browse to upload" и выберите папку

3. **Готово!**
   - Netlify автоматически создаст сайт
   - Вы получите ссылку вида: `https://your-site-name.netlify.app`
   - Ссылка будет работать всегда, даже при выключенном компьютере

**Важно:** Убедитесь, что загрузили все файлы, включая:
- index.html
- deepseek_htmlобщая.html
- admin.html
- admin.js
- data.js

## Вариант 2: GitHub Pages (требуется GitHub аккаунт)

1. **Создайте аккаунт на GitHub:**
   - https://github.com/signup

2. **Создайте новый репозиторий:**
   - Нажмите "New repository"
   - Название: `shooting-applications` (или любое другое)
   - Выберите "Public"
   - Нажмите "Create repository"

3. **Загрузите файлы:**
   - Нажмите "uploading an existing file"
   - Перетащите все файлы из папки `дут`
   - Нажмите "Commit changes"

4. **Включите GitHub Pages:**
   - Перейдите в Settings → Pages
   - Source: выберите "main" branch, folder "/ (root)"
   - Нажмите "Save"
   - Получите ссылку: `https://your-username.github.io/shooting-applications/`

---

## Вариант 3: Vercel

1. Перейдите на https://vercel.com/
2. Зарегистрируйтесь (можно через GitHub)
3. Нажмите "Add New Project"
4. Перетащите папку с проектом
5. Получите ссылку автоматически

---

## ⚠️ ВАЖНО для всех вариантов:

После размещения сайта откройте **index.html** и проверьте, что:
- Все ссылки работают
- Все файлы загружены (admin.js, data.js)
- Формы работают корректно

**Примечание:** Все данные будут храниться в localStorage каждого пользователя в браузере. Это означает, что данные не синхронизируются между разными устройствами/пользователями.
