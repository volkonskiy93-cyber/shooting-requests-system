ВАРИАНТ 2: Через GitHub веб-интерфейс
───────────────────────────────────────────────────────────────
1. Откройте: https://github.com/volkonskiy93-cyber/-2
2. Для каждого файла (index.html, admin.html, auth.js, data.js, admin.js):
   - Нажмите на файл
   - Нажмите Edit (карандаш)
   - Скопируйте содержимое из локального файла
   - Вставьте в редактор GitHub
   - Commit changes

3. Для deepseek_htmlобщая.html:
   - Найдите файл с названием содержащим "общая.html"
   - Откройте его
   - Нажмите Edit
   - Скопируйте содержимое из локального файла
   - Вставьте в редактор GitHub
   - Commit changes

ЕСЛИ VERCEL ВСЕ ЕЩЕ СКАЧИВАЕТ ФАЙЛ
═══════════════════════════════════════════════════════════════

1. Откройте Vercel Dashboard: https://vercel.com/dashboard
2. Найдите проект "-2"
3. Перейдите в Settings -> General
4. Убедитесь, что:
   - Framework Preset: Other
   - Build Command: (пусто)
   - Output Directory: .
   - Install Command: npm install (если нужно)

5. Перейдите в Deployments
6. Найдите последний deployment
7. Нажмите "..." -> Redeploy
