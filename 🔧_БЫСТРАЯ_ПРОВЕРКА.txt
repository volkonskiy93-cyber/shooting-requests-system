1️⃣  ПРОВЕРЬТЕ ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ (2 мин)
═══════════════════════════════════════════════════════════════

→ Откройте: https://vercel.com
→ Ваш проект → Settings → Environment Variables

Должны быть 5 переменных:
  ✅ SMTP_HOST = smtp.yandex.ru
  ✅ SMTP_PORT = 465
  ✅ SMTP_SECURE = true
  ✅ SMTP_USER = Volkonskiyser@yandex.ru
  ✅ SMTP_PASSWORD = [ваш пароль приложения]

⚠️ Если переменных нет или они неправильные:
   1. Добавьте/исправьте переменные
   2. Deployments → последний деплой → "..." → "Redeploy"

2️⃣  ПРОВЕРЬТЕ РАБОТУ ФУНКЦИИ (1 мин)
═══════════════════════════════════════════════════════════════

→ Откройте в браузере:
   https://2-git-main-pendehos-projects.vercel.app/api/send-email

❌ Если видите 404 или другую ошибку:
   → Функция не задеплоена
   → Проверьте, что файл api/send-email.js есть в проекте

3️⃣  ПРОВЕРЬТЕ КОНСОЛЬ БРАУЗЕРА (2 мин)
═══════════════════════════════════════════════════════════════

→ Откройте сайт: https://2-git-main-pendehos-projects.vercel.app
→ Нажмите F12 (открыть консоль)
→ Перейдите на вкладку "Console"
→ Создайте тестовую заявку
→ Нажмите "Отправить заявку"

Смотрите на ошибки:

  ❌ "SMTP credentials not configured"
     → Переменные окружения не настроены
     → Решение: см. пункт 1

  ❌ "Authentication failed"
     → Неправильный пароль приложения
     → Решение: создайте новый пароль в Yandex

  ❌ "Failed to fetch" или CORS error
     → Проблема с путём к функции
     → Решение: проверьте, что функция задеплоена

  ❌ "404 Not Found"
     → Функция не найдена
     → Решение: проверьте, что api/send-email.js есть
