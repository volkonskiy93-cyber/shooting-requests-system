## 📤 Шаг 2: Загрузка на GitHub

### Вариант A: Через веб-интерфейс GitHub (РЕКОМЕНДУЕТСЯ - проще)

1. **Откройте ваш репозиторий:** https://github.com/volkonskiy93-cyber/-2

2. **Проверьте, какие файлы уже есть:**
   - Есть ли папка `api/`?
   - Есть ли файл `package.json`?
   - Есть ли файл `vercel.json`?

3. **Если файлов нет, добавьте их:**

   **Добавить папку `api/`:**
   - Нажмите "Add file" → "Create new file"
   - Введите путь: `api/send-email.js`
   - Скопируйте содержимое из локального файла `api/send-email.js`
   - Нажмите "Commit new file"

   **Добавить `package.json`:**
   - "Add file" → "Create new file"
   - Имя: `package.json`
   - Скопируйте содержимое из локального `package.json`
   - "Commit new file"

   **Добавить `vercel.json`:**
   - "Add file" → "Create new file"
   - Имя: `vercel.json`
   - Скопируйте содержимое из локального `vercel.json`
   - "Commit new file"

4. **Обновить существующие файлы:**
   - Откройте файл (например, `email-service.js`)
   - Нажмите "Edit" (карандаш)
   - Скопируйте содержимое из локального файла
   - Нажмите "Commit changes"

### Вариант B: Через Git CLI (если Git установлен)

```bash
# 1. Перейдите в папку проекта
cd "c:\Исходники DaVinci\дут"

# 2. Инициализируйте Git (если еще не инициализирован)
git init

# 3. Добавьте удаленный репозиторий
git remote add origin https://github.com/volkonskiy93-cyber/-2.git

# 4. Добавьте все файлы
git add .

# 5. Создайте коммит
git commit -m "Добавлена serverless функция для отправки email"

# 6. Загрузите на GitHub
git push -u origin main
```

**Если получите ошибку о ветке:**
```bash
git branch -M main
git push -u origin main
```

## ✅ Шаг 3: Проверка после загрузки

1. **Обновите страницу репозитория на GitHub**
2. **Убедитесь, что все файлы загружены:**
   - Папка `api/` с файлом `send-email.js`
   - `package.json`
   - `vercel.json`
   - Обновленные `email-service.js` и `deepseek_htmlобщая.html`

3. **Проверьте Vercel:**
   - Vercel автоматически передеплоит проект при обновлении GitHub
   - Или передеплойте вручную: Vercel → Deployments → "Redeploy"

---

## 🔧 Шаг 4: Настройка Vercel для автоматического деплоя

1. **Vercel должен быть подключен к GitHub:**
   - Если проект уже на Vercel - он должен автоматически обновляться
   - Если нет - при импорте проекта выберите репозиторий из GitHub

2. **Проверьте настройки в Vercel:**
   - Settings → Git
   - Должен быть подключен ваш GitHub репозиторий

## ⚠️ Важные моменты

1. **Не загружайте конфиденциальные данные:**
   - `.env` файлы (если есть) - НЕ загружайте на GitHub
   - Пароли и ключи - только через переменные окружения Vercel

2. **`.gitignore` файл:**
   - Уже создан и настроен
   - Он игнорирует ненужные файлы

3. **После загрузки:**
   - Vercel автоматически определит изменения
   - Может потребоваться передеплой после добавления переменных окружения

## 🆘 Если что-то не работает

**Проблема: "File already exists"**
- Файл уже есть в репозитории
- Откройте файл и нажмите "Edit" для обновления

**Проблема: Vercel не обновляется**
- Проверьте подключение GitHub к Vercel
- Передеплойте вручную в Vercel панели

**Проблема: Git не работает**
- Используйте веб-интерфейс GitHub (Вариант A)
- Или установите Git: https://git-scm.com/download/win
