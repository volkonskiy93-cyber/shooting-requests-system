═══════════════════════════════════════════════════════════════
ШАГ 1: ОТКРОЙТЕ VERCEL DASHBOARD
═══════════════════════════════════════════════════════════════

Откройте: https://vercel.com/dashboard

Если не авторизованы - войдите через GitHub.

═══════════════════════════════════════════════════════════════
ШАГ 2: ДОБАВЬТЕ НОВЫЙ ПРОЕКТ
═══════════════════════════════════════════════════════════════

1. Нажмите кнопку "Add New Project" или "New Project"

2. В списке репозиториев найдите:
   shooting-requests-system

3. Если репозитория нет в списке:
   - Нажмите "Adjust GitHub App Permissions"
   - Найдите репозиторий shooting-requests-system
   - Поставьте галочку
   - Нажмите "Save"
   - Вернитесь к импорту проекта

═══════════════════════════════════════════════════════════════
ШАГ 3: НАСТРОЙТЕ ПРОЕКТ
═══════════════════════════════════════════════════════════════

После выбора репозитория настройте:

Framework Preset: Other
Root Directory: ./
Build Command: (оставьте пустым)
Output Directory: ./
Install Command: npm install (если нужно)

═══════════════════════════════════════════════════════════════
ШАГ 4: ДЕПЛОЙ
═══════════════════════════════════════════════════════════════

1. Нажмите кнопку "Deploy"
2. Дождитесь завершения (обычно 1-2 минуты)
3. Vercel автоматически даст вам ссылку на проект

═══════════════════════════════════════════════════════════════
ПРОВЕРКА ПОСЛЕ ДЕПЛОЯ
═══════════════════════════════════════════════════════════════

После успешного деплоя проверьте:

✅ Открывается страница авторизации
✅ Можно зарегистрироваться и войти
✅ Формы Фигаро и ТТК работают
✅ Панель администратора работает
✅ Кнопка "Выгрузить в DOC" работает
