Проблема: http://localhost:5000 не открывается

═══════════════════════════════════════════════
ВАРИАНТ 1: Через файл START_SERVER.bat
═══════════════════════════════════════════════

1. Найдите файл START_SERVER.bat в папке проекта
2. Дважды кликните на него
3. Должно открыться окно командной строки
4. Если видите ошибки - скопируйте их и покажите
5. Если видите "Запуск сервера на http://localhost:5000" - 
   сервер запущен!

═══════════════════════════════════════════════
ВАРИАНТ 2: Через командную строку
═══════════════════════════════════════════════

1. Откройте командную строку (cmd) или PowerShell
2. Перейдите в папку проекта:
   cd "C:\Исходники DaVinci\дут"
3. Запустите:
   python run.py
4. Должно появиться:
   "База данных инициализирована"
   "Запуск сервера на http://localhost:5000"
5. Откройте браузер и перейдите на:
   http://localhost:5000

═══════════════════════════════════════════════
ПРОВЕРКА ПРОБЛЕМ
═══════════════════════════════════════════════

Если не работает, проверьте:

1. Python установлен?
   python --version
   (должно быть Python 3.8 или выше)

2. Зависимости установлены?
   python -m pip install -r requirements.txt

3. Файлы на месте?
   - app.py
   - models.py
   - run.py
   - requirements.txt
   - templates/ (папка)
   - static/ (папка)
   - utils/ (папка)

4. Порт 5000 свободен?
   - Закройте другие приложения, которые могут использовать порт 5000

═══════════════════════════════════════════════
ЕСЛИ ЕСТЬ ОШИБКИ
═══════════════════════════════════════════════

Скопируйте полный текст ошибки из окна командной строки
и сообщите о проблеме.

Частые ошибки:

❌ "ModuleNotFoundError: No module named 'app'"
   → Вы не в правильной папке проекта
   → Используйте: cd "C:\Исходники DaVinci\дут"

❌ "Address already in use"
   → Порт 5000 занят
   → Измените порт в run.py (строка 14): port=8080

❌ "No module named 'flask'"
   → Установите зависимости:
   → python -m pip install -r requirements.txt
