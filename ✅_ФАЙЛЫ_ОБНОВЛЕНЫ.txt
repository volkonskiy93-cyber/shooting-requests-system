РЕКОМЕНДУЕМЫЙ СПОСОБ ОБНОВЛЕНИЯ
═══════════════════════════════════════════════════════════════

Из-за ограничений системы (нет Node.js и Python), самый надежный
способ обновить файлы - через веб-интерфейс GitHub:

1. Откройте: https://github.com/volkonskiy93-cyber/-2

2. Для каждого файла:
   - Нажмите на файл
   - Нажмите кнопку "Edit" (карандаш)
   - Скопируйте ВСЁ содержимое из локального файла
   - Вставьте в редактор GitHub (замените всё)
   - Прокрутите вниз → Commit changes

3. Файлы для обновления:
   ✅ index.html
   ✅ admin.html  
   ✅ auth.js
   ✅ data.js
   ✅ admin.js
   ✅ vercel.json (ВАЖНО - исправлена конфигурация!)
   ✅ package.json
   ✅ deepseek_htmlобщая.html (найдите файл с "общая" в названии)
