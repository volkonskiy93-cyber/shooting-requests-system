РЕШЕНИЕ: 3 СПОСОБА ЗАПУСКА
═══════════════════════════════════════════════

┌─────────────────────────────────────────────┐
│ СПОСОБ 1: Через файл (РЕКОМЕНДУЕТСЯ)       │
└─────────────────────────────────────────────┘

1. Откройте папку проекта:
   C:\Исходники DaVinci\дут

2. Найдите и дважды кликните на файл:
   START_SERVER.bat

3. Должно открыться окно командной строки
   с информацией о запуске.

4. Если видите:
   "✅ База данных инициализирована"
   "Запуск сервера на http://localhost:5000"
   
   → Сервер запущен! ✅

5. Откройте браузер и перейдите на:
   http://localhost:5000

┌─────────────────────────────────────────────┐
│ СПОСОБ 2: Через Python напрямую            │
└─────────────────────────────────────────────┘

1. Откройте командную строку (Win+R → cmd → Enter)

2. Скопируйте и вставьте эту команду (всю целиком):
   
   cd /d "C:\Исходники DaVinci\дут" && python diagnose_and_run.py

3. Нажмите Enter

4. Дождитесь сообщения:
   "Запуск сервера на http://localhost:5000"

5. Откройте браузер: http://localhost:5000

┌─────────────────────────────────────────────┐
│ СПОСОБ 3: Через PowerShell                 │
└─────────────────────────────────────────────┘

1. Откройте PowerShell

2. Выполните команды:

   $path = "C:\Исходники DaVinci\дут"
   Set-Location $path
   python diagnose_and_run.py

3. Дождитесь запуска сервера

4. Откройте: http://localhost:5000

═══════════════════════════════════════════════
ЕСЛИ НЕ РАБОТАЕТ
═══════════════════════════════════════════════

1. ПРОВЕРЬТЕ PYTHON:
   python --version
   (должно быть 3.8 или выше)

2. УСТАНОВИТЕ ЗАВИСИМОСТИ:
   python -m pip install -r requirements.txt

3. ПРОВЕРЬТЕ ПОРТ 5000:
   - Закройте другие программы, использующие порт 5000
   - Или измените порт в файле diagnose_and_run.py
     (строка: port=5000 → port=8080)

4. ПОСМОТРИТЕ ОШИБКИ:
   - В открывшемся окне командной строки
   - Скопируйте полный текст ошибки
