🚀 Обновление файлов на GitHub

⚠️ ВАЖНО: Этот файл должен быть открыт через локальный веб-сервер!

БЕЗ Python:
1. Установите Node.js: https://nodejs.org/
2. Откройте командную строку в этой папке
3. Выполните: npx http-server -p 8000
4. Откройте: http://localhost:8000/UPDATE_GITHUB.html

ИЛИ используйте готовый bat-файл: update.bat
