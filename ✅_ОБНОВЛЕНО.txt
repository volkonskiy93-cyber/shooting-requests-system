═══════════════════════════════════════════════════════════════

ВАРИАНТ 1: Запустите bat файл (РЕКОМЕНДУЕТСЯ)
───────────────────────────────────────────────────────────────
Дважды кликните на файл:
   ОБНОВИТЬ.bat

Этот файл запустит PowerShell скрипт update_direct.ps1,
который обновит все три файла через GitHub API.

═══════════════════════════════════════════════════════════════
ВАРИАНТ 2: Обновите вручную через GitHub
═══════════════════════════════════════════════════════════════

1. Откройте в браузере:
   https://github.com/volkonskiy93-cyber/-2

2. Для каждого файла (index.html, deepseek_htmlобщая.html, admin.html):
   - Нажмите на файл
   - Нажмите кнопку "Edit" (карандаш)
   - Скопируйте содержимое из локального файла
   - Вставьте в редактор GitHub
   - Нажмите "Commit changes"
