═══════════════════════════════════════════════
РЕШЕНИЕ ПРОБЛЕМ:
═══════════════════════════════════════════════

❌ Порт 5000 занят?
   → Измените порт в run.py (строка 14): port=8080

❌ Email не отправляется?
   → Проверьте SMTP настройки в .env
   → Для Yandex используйте пароль приложения

❌ База данных не создается?
   → Проверьте права на запись в папке instance/

❌ Модули не найдены?
   → python -m pip install -r requirements.txt
