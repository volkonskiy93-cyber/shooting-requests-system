Если deployment failed, проверьте:

═══════════════════════════════════════════════════════════════
1. ОТКРОЙТЕ ЛОГИ VERCEL
═══════════════════════════════════════════════════════════════

1. Откройте: https://vercel.com/dashboard
2. Найдите проект "-2"
3. Перейдите в Deployments
4. Откройте последний failed deployment
5. Посмотрите логи (Logs)
6. Скопируйте ошибку и отправьте мне

═══════════════════════════════════════════════════════════════
2. ПРОВЕРЬТЕ ФАЙЛЫ НА GITHUB
═══════════════════════════════════════════════════════════════

Откройте: https://github.com/volkonskiy93-cyber/-2

Убедитесь, что есть:
✅ index.html
✅ admin.html
✅ auth.js
✅ data.js
✅ admin.js
✅ vercel.json
✅ package.json
✅ deepseek_htmlобщая.html (или файл с "общая" в названии)

═══════════════════════════════════════════════════════════════
3. ЧАСТЫЕ ПРОБЛЕМЫ
═══════════════════════════════════════════════════════════════

Проблема: "Build failed"
Решение: Проверьте vercel.json и package.json

Проблема: "File not found"
Решение: Убедитесь, что все файлы в корне репозитория

Проблема: "Invalid configuration"
Решение: Проверьте синтаксис vercel.json (должен быть валидный JSON)

═══════════════════════════════════════════════════════════════
4. БЫСТРОЕ РЕШЕНИЕ
═══════════════════════════════════════════════════════════════

1. Откройте Vercel Dashboard
2. Найдите проект "-2"
3. Settings → General
4. Scroll down → Delete Project
5. Создайте проект заново, подключив GitHub репозиторий

ИЛИ

1. Deployments → Последний deployment
2. "..." → Redeploy
